# Skill: plan-ingest-and-execute

## Purpose

Guide an executor agent to ingest an approved plan, verify assumptions, perform minimal changes, and report outcomes.

## Inputs
- Approved implementation plan
- Repository path

## Procedure
1. Read plan and extract explicit file/command expectations.
2. Verify assumptions against current repository state.
3. Execute minimal edits required by the plan.
4. Run validation commands.
5. Write execution log with deviations and risks.
6. Stop and escalate with a plan amendment if assumptions fail.

## Output
- Implemented changes
- Validation results
- Execution log
