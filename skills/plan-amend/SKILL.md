# Skill: plan-amend

## Purpose

Produce a structured amendment when execution evidence shows the current plan is invalid or incomplete.

## Inputs
- Original implementation plan
- Execution evidence (errors, logs, file state)

## Procedure
1. Identify failed assumptions and collect evidence.
2. Explain why the existing plan path is blocked.
3. Propose the smallest viable amendment.
4. Define updated validation steps.
5. Request planner approval before continuing execution.

## Output
- Completed `templates/plan_amendment.md`
